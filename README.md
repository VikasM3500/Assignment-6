# 🎵 Vibe — Music Discovery Web Application

**Vibe** is an interactive, responsive single-page web application built to explore, search, and discover music albums and artists across diverse genres.

---

## 🚀 Live Demo
Check out the deployed application on GitHub Pages:  
[https://vikasm3500.github.io/Assignment-6/](https://vikasm3500.github.io/Assignment-6/)

---

## 🛠️ Features & Recent Updates
* **Single-Page Navigation:** Smooth DOM-based views for Home, Albums, Artists, and About without full page reloads.
* **Real-Time Search:** Filter albums dynamically by artist, title, or genre.
* **Responsive Dark Theme:** Mobile-friendly layout styled with Bootstrap 5 and custom CSS.
* **Code Optimization & Cleanup:** Streamlined file structure, resolved directory nesting issues, and standardized event handling across views.

---

## 💻 Tech Stack
* **HTML5** — Semantic page markup
* **CSS3 & Bootstrap 5** — Modern styling and layout
* **JavaScript (Vanilla)** — Dynamic DOM rendering and event handling
